# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)
como código de conduta.

Esperamos que todas as pessoas que participam do projeto — em issues, pull requests, discussões ou qualquer outro
espaço — interajam de forma respeitosa e acolhedora.

Comportamentos inaceitáveis podem ser reportados aos mantenedores. Todas as denúncias serão analisadas e tratadas
com confidencialidade.
